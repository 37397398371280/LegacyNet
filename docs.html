1. Architecture & ES3 Compatibility Contract

LegacyNet (v1.0.2) is a self-contained networking, asynchronous flow, WebRTC/STUN/TURN engine, and cross-edition JavaScript utility library targeting ECMAScript 3 through ECMAScript 2026 (ES26).

Syntax & Runtime Rules

  • Strict ES3 source syntax: Uses var, function, plain prototype methods, and bracket property access (["catch"], ["finally"], ["try"], ["delete"]) so legacy engines and strict ES3 parsers can parse the file without SyntaxError. No let/const, arrow functions, async/await, classes, optional chaining, or nullish coalescing are used in the library source.
  • Feature-bridged execution: At load time, detectCapabilities() inspects the host environment and populates LegacyNet.capabilities. Methods delegate to native host APIs when present and fall back to from-scratch ES3 implementations when absent.
  • Host & protocol boundaries (LegacyNet.limits): Plain ES3 JavaScript cannot open raw UDP/TCP sockets or execute native DTLS/SRTP crypto or ICE packet transport on its own; connecting over real networks and STUN/TURN/WebRTC relies on host capabilities (fetch, XMLHttpRequest / ActiveXObject, WebSocket, RTCPeerConnection and prefixed variants), while Same-Origin Policy, CORS, and TLS are enforced by the host.

  • Edition summary: detectedEdition reports the highest detected feature tier across "ES2026/ES17+", "ES16/ES2025+", "ES15/ES2024+", "ES14/ES2023+", "ES13/ES2022+", "ES12/ES2021+", "ES11/ES2020+", "ES10/ES2019+", "ES8/ES2017+", "ES7/ES2016+", "ES6+", "ES5+", and "ES3".
  • Language & standard flags: es5ArrayIsArray, es5Json, es5ObjectKeys, es5DateNow, es6Promise, es6ObjectAssign, es7Includes, es8ObjectEntries, es10Flat, es11GlobalThis, es12ReplaceAll, es13At, es14ArrayCopy, es15GroupBy, es16PromiseTry.
  • ES2026 flags: es2026ErrorIsError, es2026MathSumPrecise, es2026FromAsync, es2026Uint8Base64, es2026JsonRaw, es2026MapGetOrInsert, es2026IteratorConcat.
  • Transport & media flags: fetch, xhr (XMLHttpRequest or IE ActiveXObject XMLHTTP), abortController, webSocket, rtcPeerConnection, rtcPrefixed, formData, blob, arrayBuffer, and streams.

3. Asynchronous Flow & Combinators

Deferred provides promise-like chaining (then, ["catch"], ["finally"]), async reaction scheduling via setTimeout(..., 0) (falling back to direct invocation when unavailable), self-resolution guards, thenable unwrapping, and cancellation.

Deferred Methods

  • .then(onFulfilled, onRejected) -> Deferred: Registers fulfillment and rejection handlers and returns a chained Deferred.
  • ["catch"](onRejected) -> Deferred: Equivalent to .then(null, onRejected).
  • ["finally"](onFinally) -> Deferred: Runs a cleanup callback on fulfillment or rejection (awaiting returned thenables) while preserving the original value or error.
  • .abort(reason) -> void: Marks the Deferred aborted, calls onAbort(reason) if provided, and rejects with an Error having err.code = "ABORTED".
  • .toNativePromise() -> Promise | null: Wraps the Deferred in root.Promise when available, or returns null.

Top-Level Async Helpers

  • LegacyNet.deferred(onAbort) -> Deferred: Creates a new Deferred.
  • LegacyNet.all(items) -> Deferred: Resolves with an array of values when all items fulfill; rejects on the first rejection.
  • LegacyNet.race(items) -> Deferred: Settles with the first item to fulfill or reject.
  • LegacyNet.any(items) -> Deferred: Resolves with the first fulfilled item; if all reject, rejects with an Error whose .errors array contains each rejection reason.
  • LegacyNet.allSettled(items) -> Deferred: Resolves with { status: "fulfilled", value } or { status: "rejected", reason } objects once all items settle.
  • LegacyNet.withResolvers() -> object: Returns { promise, nativePromise, resolve, reject }, coordinating with Promise.withResolvers when present.
  • LegacyNet.tryCall(fn, thisArg, argsArr) -> Deferred: Executes fn asynchronously and resolves with its result or rejects with any thrown error.
  • LegacyNet.fromAsync(source, mapFn, thisArg) -> Deferred: Uses Array.fromAsync when available, or maps array-like/single values into a resolved Deferred array.

4. JSON & Raw JSON (LegacyNet.json)

  • LegacyNet.json.stringify(val) -> string: Serializes raw JSON wrappers directly, delegates to JSON.stringify when present, or uses es3Stringify across primitives, arrays, and own enumerable keys.
  • LegacyNet.json.parse(text, reviver) -> any: Delegates to JSON.parse when present, or runs regex-validated es3Parse with recursive reviver support and { source } context metadata.
  • LegacyNet.json.rawJSON(rawText) -> object: Uses JSON.rawJSON when available, or returns { __legacyRawJson: String(rawText) }.
  • LegacyNet.json.isRawJSON(val) -> boolean: Checks JSON.isRawJSON when available or detects the internal raw JSON wrapper.

5. HTTP Client (LegacyNet.request)

LegacyNet.request(opts, callback) returns a Deferred and optionally invokes callback(err, payload).

Options (opts)

  • url (string), method (string, default "GET"), params (object serialized to key=value query string).
  • headers (object): Sets Content-Type: application/json automatically for non-binary/FormData plain objects or raw JSON wrappers on non-GET/HEAD requests unless already specified.
  • body (any): Stringifies plain objects/raw JSON wrappers; passes FormData, Blob, ArrayBuffer, ArrayBufferView, or strings through.
  • transport (string): Set to "xhr" to bypass fetch even if fetch exists; otherwise fetch is preferred, falling back to XMLHttpRequest and then IE ActiveXObject (Msxml2.XMLHTTP.6.0, Msxml2.XMLHTTP.3.0, Microsoft.XMLHTTP).
  • responseType (string): "text" (default), "json", "arraybuffer", or "blob".
  • parseJson (boolean) and reviver (function): Parses string bodies into payload.json via safeParse.
  • credentials (string), withCredentials (boolean), failOnHttpError (boolean), and cause (any, attached via withCause).
  • timeout (number in ms), retries (number), and retryDelay (number, default 250 ms): Retries transient transport failures, timeouts (err.timeout = true), and HTTP statuses 408, 429, and 500–599 with linear backoff (retryDelay * attempt), without retrying user aborts (err.code === "ABORTED").

Response & Cancellation

  • Resolved payload: { status, ok, body, stream, transport, readStream } (plus .json when parsed).
  • payload.readStream(onChunk, onDone) streams chunks via ReadableStream.getReader() when available or emits the buffered XHR text once.
  • Calling req.abort(reason) clears timers, aborts AbortController or xhr, and rejects the Deferred.

6. WebSockets (LegacyNet.connectSocket)

LegacyNet.connectSocket(url, protocols, sockOpts) -> Deferred:

  • Rejects if root.WebSocket is unavailable or construction fails.
  • Applies optional sockOpts.binaryType and optional sockOpts.pingInterval + sockOpts.pingPayload (default '{"type":"ping"}'), sending heartbeats while socket.readyState === 1 and clearing the interval on close, error, or stopPing().
  • Resolves with { socket, event, stopPing }.

7. WebRTC, STUN/TURN, SDP & Signaling Engine (LegacyNet.rtc)

LegacyNet.rtc provides ES3-written helpers and a peer/signaling engine that connects to real STUN/TURN servers and remote WebRTC peers through the host's peer connection implementation (RTCPeerConnection, webkitRTCPeerConnection, or mozRTCPeerConnection).

ICE, STUN & TURN Helpers

  • LegacyNet.rtc.hasNativeWebRtc (boolean): Whether a supported peer connection constructor was detected at load time.
  • LegacyNet.rtc.parseIceUrl(rawUrl) -> object | null: Parses stun:, stuns:, turn:, and turns: URLs (IPv4, bracketed IPv6, explicit or default ports 3478/5349, and ?transport= query params) into { raw, scheme, isTurn, isTls, host, port, transport }.
  • LegacyNet.rtc.normalizeIceServers(input) -> object: Normalizes string or { urls, username, credential, credentialType } server entries and returns { iceServers, stunServers, turnServers }.
  • LegacyNet.rtc.createStunTransactionId() -> string: Generates a 12-byte (96-bit) hex transaction ID.

SDP & ICE Candidate Helpers

  • LegacyNet.rtc.buildSdp(opts) -> string: Builds a CRLF-delimited SDP offer or answer with session/media lines (v=, o=, s=, t=, m=application ... UDP/DTLS/SCTP webrtc-datachannel, c=, a=ice-ufrag:, a=ice-pwd:, a=fingerprint:, a=setup:, a=mid:, a=sctp-port:, a=max-message-size:, and optional a=candidate: lines).
  • LegacyNet.rtc.parseSdp(sdpText) -> object: Extracts version, origin, sessionName, iceUfrag, icePwd, fingerprint, setup, mid, sctpPort, mediaSections, and candidates.
  • LegacyNet.rtc.normalizeCandidate(candInput) -> object | null: Normalizes string or object candidates into { candidate, sdpMid, sdpMLineIndex, usernameFragment }.

LegacyNet.rtc.createEngine(opts)

Creates a peer and signaling controller configured with { iceServers, rtcConfig, sendSignal, autoAnswer, emitEndOfCandidates }:

  • Properties: hasNativeWebRtc, peerConnection, iceServers, stunServers, turnServers, localCandidates, channels.
  • State & channels: getState() returns { connectionState, iceGatheringState, remoteDescriptionSet, queuedCandidates }; createDataChannel(label, channelOpts) creates and wraps a channel with { label, channel, readyState, send, close }.
  • Negotiation & signaling:
    • createOffer(offerOpts) -> Deferred and createAnswer(answerOpts) -> Deferred: Support both Promise-returning and callback-style host WebRTC APIs, set local descriptions, emit/send { type, sdp, parsed } signals, and mark ICE gathering as "gathering".
    • handleSignal(signalMsg) -> Deferred: Parses JSON strings via safeParse if needed and handles "offer", "answer" (auto-answering when autoAnswer !== false), "candidate" (buffering candidates until setRemoteDescription completes, then flushing them), and "end-of-candidates".
    • addRemoteCandidate(rawCandidate) -> Deferred: Normalizes and queues or adds a remote ICE candidate.
  • Events & teardown: on(eventName, fn), off(eventName, fn) for "stateChange", "iceGatheringStateChange", "iceCandidate", "signal", "dataChannel", "message", "track", "error", and "close"; close() closes data channels and the peer connection and emits "close".

9. End-to-End Usage Example

var rtc = LegacyNet.rtc.createEngine({
  iceServers: [
    { urls: "stun:stun.l.google.com:19302" },
    {
      urls: ["turn:turn.example.com:3478?transport=udp", "turns:turn.example.com:5349?transport=tcp"],
      username: "ephemeral-user",
      credential: "ephemeral-secret"
    }
  ],
  sendSignal: function (msg) {
    LegacyNet.request({
      url: "https://example.com/signal",
      method: "POST",
      body: msg,
      timeout: 3000,
      retries: 1
    });
  }
});

rtc.on("dataChannel", function (ch) {
  ch.send(LegacyNet.json.stringify({
    edition: LegacyNet.capabilities.detectedEdition,
    preciseSum: LegacyNet.utils.sumPrecise([0.1, 0.2, 0.3]),
    b64: LegacyNet.utils.toBase64([111, 107])
  }));
});

rtc.on("message", function (ev) {
  // Handle incoming data channel message ev.data on channel ev.label
});

rtc.createDataChannel("control");
rtc.createOffer()["catch"](function (err) {
  // Handle missing WebRTC support or negotiation error
});
